# 02 · 接入 UE5（Live Link FreeD，零代码）

本程序输出 **标准 Vinten Free-D D1 报文**，UE5 自带 `Live Link FreeD` 插件即可接收，
不需要编译任何 C++ 插件。

> 已验证：UE 5.4 / 5.5 / 5.6 安装目录中均存在 LiveLinkFreeD；
> 5.7 文档仍有该插件。5.8 未在本机实测，若被移除则改用第二阶段的 JSON 插件。

---

## 1. 启用插件

`编辑 → 插件`，搜索并勾选：

- **Live Link**
- **Live Link FreeD**

重启编辑器。

---

## 2. 添加 Free-D 源

`窗口 → Live Link` → `Source → LiveLinkFreeD Source`：

| 项 | 值 |
|---|---|
| IP Address | `127.0.0.1` |
| Port Number | `40000` |

- 如果 Bridge 在另一台机器：IP 填 Bridge 所在机器地址；
  或在 Bridge 里把目标 IP 改成 UE 机器的地址。
- 端口必须与 Bridge 的「Free-D 端口」一致。

成功后 Subject 列表出现 **`Camera 0`**（数字 = Bridge 里的 Free-D Camera ID）。

### 看不到 Subject？

1. 确认 Bridge 状态是「跟踪中」，Pose 频率 > 0。
2. 用监视器确认本机 40000 端口有包：
   ```powershell
   python tools\pose_monitor.py --seconds 3
   ```
3. Windows 防火墙：首次运行时允许 `DS80Bridge.exe` 访问专用网络。
4. UE 的 Source 端口填错（默认 40000，不要填 40001）。
5. 同一端口被别的软件占用 —— 换端口（Bridge 与 UE 两边一起改）。

---

## 3. 驱动 CineCameraActor

1. 场景里放一个 **Cine Camera Actor**。
2. 选中它 → Details → `Add Component` → **Live Link Controller**。
3. 该组件的 `Subject Representation` 选 `Camera 0`。
4. （可选）把 `Live Link Controller` 的 `Component Role` 设为
   `LiveLinkCameraRole`，这样镜头参数也能被驱动（当前 DS80 不提供变焦/对焦）。

转动/移动 DS80，虚拟摄像机应同步。

> 如果相机不动：检查 Subject 是否在 Live Link 面板里持续刷新（勾选
> `View Options → Show Frame Data`），以及 Controller 的 Subject 是否选对。

## 4. 坐标系与方向核对（重要）

### 两套坐标

| | Free-D 世界系 | UE 世界系 |
|---|---|---|
| 右 | +X | +Y |
| 前 | +Y | +X |
| 上 | +Z | +Z |
| 单位 | 毫米 | 厘米 |
| 手性 | 右手 | 左手 |

UE 的 FreeD 插件负责这套换算。**前提是 Bridge 发出的 Pan/Tilt/Roll 和位置符合 Free-D 定义**，
Bridge 已经按 Vinten 手册实现：

- Pan：绕竖直轴，向右为正（俯视顺时针）
- Tilt：抬头为正
- Roll：从机后看顺时针为正
- 位置：X 右 / Y 前 / Z 上，单位 1/64 mm

### 现场核对表

把 DS80 固定到摄像机上，做下面六个动作，观察 UE 里虚拟相机的反应：

| 真实动作 | 期望 | 若方向相反 |
|---|---|---|
| 摄像机向右平移 | 虚拟相机向右 | 勾选「反向 X」 |
| 摄像机向前推 | 虚拟相机向前 | 勾选「反向 Y」 |
| 摄像机升高 | 虚拟相机升高 | 勾选「反向 Z」 |
| 向右摇摄 | 虚拟相机向右转 | 勾选「反向 Pan」 |
| 抬头 | 虚拟相机抬头 | 勾选「反向 Tilt」 |
| 向右倾斜 | 虚拟相机向右倾斜 | 勾选「反向 Roll」 |

> 注意：轴向问题有兩種來源——(1) DS80 设备坐标系与假设不符；
> (2) Free-D 角度符号约定。先确认「设备坐标系」选对（见下），再用方向校正微调。

### 设备坐标系预设

Bridge 的「标定」页有「设备坐标系」下拉框：

| 预设 | 适用 | 含义 |
|---|---|---|
| **X 右 / Y 上 / Z 后（右手）** | 默认 | 常见相机/IMU 右手系，光轴朝 -Z |
| **X 前 / Y 左 / Z 上（ROS）** | 若默认轴向完全不对 | ROS REP-103 机体坐标系 |

判断方法：静止时把 DS80 水平放置、镜头朝前，看 Bridge 的 Pan/Tilt/Roll 是否接近 0；
若 Roll 接近 ±90°，说明设备坐标系的“上”方向判断错了，换另一个预设。

如果两个预设都不对，先用方向校正把 6 个轴调对，再把结果记录下来反馈，
我们可以在下一版加一个「自定义轴映射」。

## 5. 原点与安装偏移

### 重置原点

把摄像机摆到拍摄起点、对准想要的初始方向，点 **重置原点 (R)**：

- 位置归零
- 航向（Pan）归零
- Pitch / Roll 保持不变

UE 里的虚拟相机就会从该点、该朝向开始。

### 安装偏移

DS80 通常不在摄像机光心上（例如装在冷靴上、镜头后方 8cm、上方 12cm）。
在「标定」页填：

- 安装偏移 X/Y/Z（mm）：以**摄像机局部坐标**表示，X 右、Y 前、Z 上，
  即“从 DS80 指向摄像机光心”的向量。
- 安装旋转 Yaw/Pitch/Roll（°）：DS80 与摄像机光轴不平行时的角度差。

例：DS80 在摄像机上方 12cm、后方 8cm：

```
安装偏移 X = 0
安装偏移 Y = 80      (光心在 DS80 前方 80mm)
安装偏移 Z = -120    (光心在 DS80 下方 120mm)
```

## 6. 平滑与延迟

- SLAM 输出本身已做融合，**默认关闭平滑**。
- 若实拍觉得轻微抖动，勾选「启用平滑滤波」，时间常数从 `0.02` 开始试，
  一般不超过 `0.05`（越大越顺，但延迟越明显）。
- 延迟主要来自：SLAM 融合（约 10–30ms）+ USB + UDP（<1ms）+ UE 渲染。
  Bridge 显示的「数据年龄」是“距上一帧”的时间，不是传感器延迟。

## 8. 5.8 兼容性说明

UE 5.8 尚未在本机安装，无法实测。风险点：

- `Live Link FreeD` 插件被移除或改名；
- FreeD 解码器的轴向约定变化。

规避方案（第二阶段）：自绘 `DS80LiveLink` 插件，直接接收本程序的 JSON（40001 端口），
推送 `FLiveLinkCameraFrameData`。这样坐标系、单位、状态字段完全由我们控制，
不依赖 UE 内置 FreeD 的实现细节。
